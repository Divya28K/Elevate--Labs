🚀 Features
✅ Add new tasks
✅ Mark tasks as complete (click to toggle)
✅ Remove individual tasks
✅ Instant UI updates (no page reload)
✅ Keyboard support (Enter key to add)

💡 How to Use
1.Clone or Download this repository.
2.Make sure all files (index.html, style.css, index.js) are in the same directory.
3.Open index.html in any modern web browser.
4.Start managing your tasks!

🧪 Testing
• Add a Task: Type a task in the input field and click Add or press Enter.
• Complete a Task: Click on the task text to mark it as done.
• Delete a Task: Click the Remove button next to any task.
